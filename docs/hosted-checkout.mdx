# Checkout Hébergé

Le **Checkout Hébergé** est le moyen le plus rapide d'encaisser des paiements. Vous transmettez les paramètres de la commande à PichFlow, qui génère une session et vous renvoie une URL sécurisée (`checkout_url`) vers laquelle rediriger votre client.

---

## 1. Créer une session de checkout

Effectuez une requête `POST` vers `/v1/checkout-sessions` avec votre clé API marchand :

```bash
curl -X POST https://api.pichflow.com/v1/checkout-sessions \
  -H "Authorization: Bearer sk_test_votre_cle" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "12500.00",
    "currency": "XOF",
    "country": "BJ",
    "customer_name": "Amina Touré",
    "customer_email": "amina.toure@example.com",
    "customer_phone": "+22996112233",
    "description": "Panier #ORD-4591",
    "return_url": "https://maboutique.com/checkout/merci?ref=ORD-4591",
    "fee_charge_mode": "ADD_ON"
  }'
```

### Paramètres de la requête

| Champ | Type | Obligatoire | Description |
| :--- | :--- | :--- | :--- |
| `amount` | `string` | **Oui** | Montant au format chaîne décimale (ex: `"12500.00"`). |
| `currency` | `string` | **Oui** | Code devise ISO (ex: `"XOF"`). |
| `customer_name` | `string` | **Oui** | Nom complet du client. |
| `customer_email` | `string` | **Oui** | Email du client (utilisé pour les notifications et reçus). |
| `customer_phone` | `string` | Non | Téléphone au format international (ex: `+229...`). |
| `country` | `string` | Non | Code pays ISO-2 (ex: `"BJ"`, `"CI"`, `"SN"`, `"TG"`). |
| `return_url` | `string` | Non | URL de redirection du client après validation du paiement. |
| `fee_charge_mode` | `string` | Non | `"ADD_ON"` (frais en sus) ou `"DEDUCTED"` (frais déduits). |

---

## 2. Réponse de l'API

```json
{
  "success": true,
  "data": {
    "id": "cs_01h8a9bcdef234",
    "amount": "12500.00",
    "currency": "XOF",
    "status": "pending",
    "checkout_url": "https://checkout.saspay.me/pay/cs_01h8a9bcdef234",
    "expires_at": "2026-10-15T01:30:00Z"
  }
}
```

---

## 3. Redirection et Traitement

Dès réception de la réponse :
1. Redirigez le navigateur de l'utilisateur vers `checkout_url`.
2. Le client sélectionne son moyen de paiement (MTN, Moov, Celtiis, Wave, Carte) et confirme l'opération.
3. Dès confirmation, PichFlow reçoit le webhook SasPay, crédite votre wallet et notifie vos serveurs via webhook.
4. L'utilisateur est reconduit sur votre `return_url`.

> ⚠️ **Sécurité** : Ne considérez **jamais** la simple arrivée sur votre page `return_url` comme une preuve que le paiement est réussi. Validez toujours l'événement via le webhook serveur ou via l'endpoint de vérification `/v1/payments/:id/verify`.
