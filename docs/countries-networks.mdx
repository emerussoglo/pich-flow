# Pays & Réseaux Télécoms Supportés

Pour éviter toute obsolescence technique, PichFlow charge dynamiquement les pays, les réseaux actifs et les grilles tarifaires directement depuis les routes de référence SasPay.

---

## 1. Endpoints de Référence Dynamiques

### Liste des Pays Disponibles
```bash
curl -X GET https://api.pichflow.com/v1/reference/countries \
  -H "Authorization: Bearer sk_test_votre_cle"
```

### Liste des Réseaux Télécoms
```bash
curl -X GET https://api.pichflow.com/v1/reference/networks \
  -H "Authorization: Bearer sk_test_votre_cle"
```

### Grille Tarifaire du Marchand
```bash
curl -X GET https://api.pichflow.com/v1/reference/rates \
  -H "Authorization: Bearer sk_test_votre_cle"
```

## Bonnes Pratiques de Validation Téléphonique

1. **Format E.164** : Transmettez toujours les numéros préfixés par leur indicatif international avec le signe `+` (ex: `+22997001234`).
2. **Nettoyage des espaces** : PichFlow nettoie automatiquement les espaces et tirets, mais fournir un numéro normalisé accélère le routage vers l'opérateur.
3. **Disponibilité des réseaux** : Si un opérateur est temporairement en maintenance côté SasPay, l'API renvoie son état réel et empêche la soumission du paiement.
