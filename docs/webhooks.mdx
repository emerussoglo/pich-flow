# Webhooks & Sécurité

Les webhooks permettent à PichFlow et à SasPay de notifier votre infrastructure backend en temps réel dès qu'un paiement, retrait ou transfert change d'état.

---

## 1. En-têtes HTTP Reçus

Chaque requête webhook envoyée vers votre endpoint contient les en-têtes suivants :

| En-tête | Description |
| :--- | :--- |
| `X-Webhook-Signature` | Signature hexadécimale HMAC SHA-256 calculée sur le corps brut de la requête. |
| `X-Webhook-Timestamp` | Horodatage Unix en secondes au moment de l'émission. |
| `Content-Type` | `application/json` |

---

## 2. Algorithme de Vérification de Signature (HMAC SHA-256)

Pour vous assurer que la notification provient bien de PichFlow / SasPay et n'a pas été interceptée ou modifiée en cours de route :

1. **Vérifiez l'âge de l'horodatage** : Rejetez immédiatement toute requête dont le `X-Webhook-Timestamp` diffère de plus de **300 secondes** (5 minutes) par rapport à l'heure courante de votre serveur afin de bloquer les attaques par rejeu.
2. **Construisez la chaîne de signature** : Concaténez l'horodatage et le **corps brut (raw body)** de la requête séparés par un point :
   ```text
   payload = `${timestamp}.${rawBody}`
   ```
3. **Calculez le HMAC SHA-256** avec votre clé secrète webhook (`whsec_...`).
4. **Comparez en temps constant** (`crypto.timingSafeEqual`) pour prévenir les attaques temporelles (timing attacks).

### Exemple d'implémentation en Node.js / TypeScript :

```typescript
import crypto from 'crypto';
import { Request, Response } from 'express';

export function handleWebhook(req: Request, res: Response) {
  const signature = req.headers['x-webhook-signature'] as string;
  const timestamp = req.headers['x-webhook-timestamp'] as string;
  const rawBody = (req as any).rawBody || JSON.stringify(req.body);
  const secret = process.env.PICHFLOW_WEBHOOK_SECRET!;

  // 1. Contrôle d'expiration (tolérance 300s)
  const now = Math.floor(Date.now() / 1000);
  const eventTime = parseInt(timestamp, 10);
  if (isNaN(eventTime) || Math.abs(now - eventTime) > 300) {
    return res.status(400).send('Horodatage expiré ou invalide.');
  }

  // 2. Calcul du HMAC SHA-256
  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(`${timestamp}.${rawBody}`)
    .digest('hex');

  // 3. Comparaison sécurisée en temps constant
  const sigBuffer = Buffer.from(signature.toLowerCase(), 'utf8');
  const expBuffer = Buffer.from(expectedSignature.toLowerCase(), 'utf8');

  if (sigBuffer.length !== expBuffer.length || !crypto.timingSafeEqual(sigBuffer, expBuffer)) {
    return res.status(400).send('Signature webhook invalide.');
  }

  // 4. Traitement idempotent de l'événement
  const event = req.body;
  if (event.event === 'transaction.success') {
    const tx = event.data;
    console.log(`Paiement confirmé : ${tx.reference} pour un montant de ${tx.amount}`);
    // Mettre à jour votre commande en base de données
  }

  // Toujours renvoyer un code 200 OK
  res.status(200).json({ received: true });
}
```

## 3. Événements Pris en Charge

| Événement | Description |
| :--- | :--- |
| `transaction.success` | Le paiement client a été validé avec succès par l'opérateur. |
| `transaction.failed` | La tentative de paiement a échoué (solde insuffisant, code erroné, timeout). |
| `transaction.cancelled` | Le client a annulé la saisie ou la redirection. |
| `settlement.success` | Le virement de retrait (payout) est confirmé sur le compte bénéficiaire. |
| `settlement.failed` | Le virement de retrait a échoué et le solde a été réintégré. |
| `webhook.test` | Événement émis lors d'un test ping depuis le Dashboard développeur. |
