# Retraits & Transferts Sortants (Payouts)

Le module de Payout permet d'ordonner des virements automatiques depuis votre solde PichFlow vers les comptes Mobile Money de vos partenaires, fournisseurs ou utilisateurs.

---

## Prérequis de Sécurité SasPay Obligatoires

> ⚠️ **Sécurité Critique : Liste Blanche IP (IP Whitelisting)**
> Conformément à la politique de sécurité stricte de SasPay, tout appel à l'endpoint de Payout (`POST /v1/payouts/initialize`) initié par clé d'API exige que **l'adresse IP publique de votre serveur soit préalablement déclarée dans votre tableau de bord SasPay**.
> 
> Si votre IP n'est pas autorisée, SasPay renvoie immédiatement une erreur HTTP `403 Forbidden` (`ip_not_whitelisted`).

---

## 1. Initialiser un Retrait (cURL)

L'en-tête `Idempotency-Key` est **strictement obligatoire** pour prévenir tout risque de double virement lors des réessais réseau.

```bash
curl -X POST https://api.pichflow.com/v1/payouts/initialize \
  -H "Authorization: Bearer sk_live_votre_cle" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: d4e5f6a7-8901-4b2c-aef0-123456789abc" \
  -d '{
    "amount": "50000.00",
    "currency": "XOF",
    "country": "BJ",
    "network": "mtn_bj",
    "recipient_name": "Cabinet Conseils SAS",
    "recipient_phone": "+22997123456",
    "description": "Règlement Facture F-2026-09"
  }'
```

### Réponse :

```json
{
  "success": true,
  "data": {
    "id": "payout_98124701bc",
    "reference": "WDR-PF-120934",
    "status": "pending",
    "amount": "50000.00",
    "fee": "500.00",
    "net_amount": "49500.00",
    "currency": "XOF",
    "recipient_phone": "+22997123456"
  }
}
```

---

## 2. Vérifier le Statut d'un Retrait

```bash
curl -X GET https://api.pichflow.com/v1/payouts/payout_98124701bc/verify \
  -H "Authorization: Bearer sk_live_votre_cle"
```

### Statuts des Retraits :

| Statut | Description |
| :--- | :--- |
| `pending` | Demande en cours de traitement par le réseau télécom ou la compensation bancaire. |
| `completed` | Fonds déposés avec succès sur le wallet ou compte bancaire du bénéficiaire. |
| `failed` | Numéro bénéficiaire inactif, compte plafonné ou rejet opérateur. Le solde du marchand est automatiquement recrédité. |
