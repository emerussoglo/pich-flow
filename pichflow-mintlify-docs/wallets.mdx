# Wallets & Gestion Multi-Devises

PichFlow permet aux marchands d'opérer des comptes multi-devises à travers plusieurs pays africains tout en conservant une vision consolidée de leurs finances.

---

## 1. Consulter les Soldes Réels des Wallets

Pour interroger vos soldes réels déclarés auprès de la passerelle SasPay :

```bash
curl -X GET https://api.pichflow.com/v1/wallets/balances \
  -H "Authorization: Bearer sk_live_votre_cle"
```

### Réponse officielle :

```json
{
  "success": true,
  "data": [
    {
      "currency": "XOF",
      "country": "BJ",
      "balance": "428500.00",
      "available_balance": "428500.00",
      "pending_balance": "0.00"
    },
    {
      "currency": "XOF",
      "country": "CI",
      "balance": "154200.00",
      "available_balance": "154200.00",
      "pending_balance": "0.00"
    }
  ]
}
```

> **Zéro Simulation** : PichFlow ne simule aucun solde financier. Les données affichées reflètent strictement les relevés de trésorerie de votre compte SasPay marchand.

---

## 2. Consulter les Taux de Change Officiels

Pour obtenir la grille des taux de change appliqués lors des règlements ou conversions :

```bash
curl -X GET https://api.pichflow.com/v1/wallets/rates \
  -H "Authorization: Bearer sk_test_votre_cle"
```

---

## 3. Transfert Inter-Wallets

Pour transférer des fonds d'un wallet à un autre (ex: transférer du solde XOF Bénin vers XOF Côte d'Ivoire) :

```bash
curl -X POST https://api.pichflow.com/v1/wallets/transfer \
  -H "Authorization: Bearer sk_live_votre_cle" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: a1b2c3d4-e5f6-7890-1234-56789abcdef0" \
  -d '{
    "from_country": "BJ",
    "to_country": "CI",
    "from_amount": "50000.00"
  }'
```

Le serveur attend `from_country`, `to_country` et `from_amount`. Il génère une clé d'idempotence si l'en-tête n'est pas fourni.
