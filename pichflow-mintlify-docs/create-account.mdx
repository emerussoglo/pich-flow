# Créer un compte développeur

Le tableau de bord PichFlow permet de créer un compte marchand et d'accéder ensuite au centre développeur.

## Inscription

1. Ouvrez le [tableau de bord PichFlow](https://dashboard.pichflow.com) et choisissez l'inscription.
2. Renseignez votre nom complet, votre adresse e-mail, votre pays et un mot de passe.
3. Confirmez le mot de passe et acceptez les conditions affichées par l'application.
4. Un code de confirmation à six chiffres est envoyé par e-mail. Saisissez-le pour confirmer l'adresse et accéder au tableau de bord.

Le code serveur exige un nom complet, une adresse e-mail valide et un mot de passe d'au moins huit caractères. Le code de confirmation expire après 15 minutes. Si l'e-mail ne paraît pas, utilisez l'action de renvoi du code dans l'application.

## Obtenir les clés API

Après connexion, ouvrez **Centre Développeur > Clés API** et générez une paire de clés. La procédure d'affichage et les préfixes sont décrits dans [Authentification](./authentication).

> Les conditions d'éligibilité, la validation d'identité/KYC et la disponibilité régionale ne sont pas détaillées dans les fichiers audités. Consultez le tableau de bord ou contactez le support PichFlow pour ces points.
