# Créer un compte développeur

Le code d'inscription du serveur requiert un nom complet, une adresse e-mail valide et un mot de passe d'au moins huit caractères. Le compte est créé non vérifié; un code de confirmation est envoyé par e-mail et expire après 15 minutes.

## Parcours

1. Ouvrez l'application PichFlow utilisée par votre organisation et choisissez l'inscription. L'URL publique du tableau de bord n'est pas définie dans ce dépôt.
2. Fournissez votre nom, votre adresse e-mail, votre mot de passe, et éventuellement le pays et le téléphone.
3. Saisissez le code de vérification reçu par e-mail.
4. Une fois connecté, ouvrez le centre développeur pour générer les clés.

Le formulaire du tableau de bord est l'interface de création de compte; l'API documentée ici est l'API marchande et ne remplace pas ce parcours. Les conditions commerciales, le processus KYC et les critères d'activation Live ne sont pas définis par les fichiers audités.

## Obtenir les clés

Le serveur génère une paire de clés Sandbox et Live via la route du tableau de bord `POST /api/developer/keys`, protégée par la session du compte. La clé complète est renvoyée lors de sa création; conservez-la dans un gestionnaire de secrets et ne l'intégrez jamais dans le navigateur.

Voir [Authentification et clés API](./authentication).
