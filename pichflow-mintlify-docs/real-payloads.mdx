# Exemples de payloads SasPay

Les exemples ci-dessous sont repris des pages de documentation existantes. Ils ne sont pas attestés comme captures de réponses de production ; vérifiez le schéma et les valeurs dans votre environnement avant de les utiliser comme contrat.
