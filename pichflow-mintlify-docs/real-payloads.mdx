# Exemples de payloads

Les exemples de requête ci-dessous reflètent les champs lus par les handlers. Ils utilisent des données fictives et ne sont pas des captures de réponses de production.

## Softpay — corps accepté

```json
{
  "amount": "5000.00",
  "currency": "XOF",
  "country": "BJ",
  "network": "mtn_bj",
  "customer": {
    "first_name": "Awa",
    "last_name": "Exemple",
    "email": "awa@example.test",
    "phone": "+22997000000"
  },
  "description": "Commande de démonstration"
}
```

Le handler exige `amount`, `network` et `customer`. Il renvoie `success`, `environment` et le résultat du fournisseur sous `data` si celui-ci réussit.

## Checkout — corps accepté

```json
{
  "amount": "12500.00",
  "currency": "XOF",
  "country": "BJ",
  "customer_name": "Awa Exemple",
  "customer_email": "awa@example.test",
  "customer_phone": "+22997000000",
  "return_url": "https://shop.example.test/return"
}
```

Le handler exige `amount`, `customer_name` et `customer_email`. Sa réponse enveloppe les données fournisseur sous `data`; les champs précis de cette donnée ne sont pas garantis par le serveur PichFlow.

## Transfert inter-pays — corps accepté

```json
{
  "from_country": "BJ",
  "to_country": "CI",
  "from_amount": "25000.00"
}
```

Le corps n'inclut pas les champs de réseau, de client ou de devise dans le handler PichFlow.
