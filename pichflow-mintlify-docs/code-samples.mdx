# Exemples de code

Les exemples sont locaux afin de ne pas présenter comme confirmé un domaine de production absent de la configuration. Définissez `PICHFLOW_API_BASE_URL` selon les indications fournies par l'exploitant avant un déploiement; pour le serveur local, utilisez `http://localhost:3000`.

## cURL : créer une session hébergée

```bash
curl -X POST "$PICHFLOW_API_BASE_URL/api/v1/checkout-sessions" \
  -H "Authorization: Bearer $PICHFLOW_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": "15000.00",
    "currency": "XOF",
    "customer_name": "Awa Exemple",
    "customer_email": "awa@example.test",
    "return_url": "https://shop.example.test/payment-return"
  }'
```

## TypeScript / Node.js

```ts
const baseUrl = process.env.PICHFLOW_API_BASE_URL ?? "http://localhost:3000";
const apiKey = process.env.PICHFLOW_API_KEY;

if (!apiKey) throw new Error("PICHFLOW_API_KEY doit être configurée côté serveur");

const response = await fetch(`${baseUrl}/api/v1/payments/softpay`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${apiKey}`,
    "Content-Type": "application/json",
    "Idempotency-Key": crypto.randomUUID(),
  },
  body: JSON.stringify({
    amount: "15000.00",
    currency: "XOF",
    country: "BJ",
    network: "mtn_bj",
    customer: {
      first_name: "Awa",
      last_name: "Exemple",
      email: "awa@example.test",
      phone: "+22997000000",
    },
  }),
});

const contentType = response.headers.get("content-type") ?? "";
const text = await response.text();
if (!contentType.includes("application/json")) {
  throw new Error(`Réponse non JSON (HTTP ${response.status})`);
}
const result = JSON.parse(text);
if (!response.ok || result.success !== true) {
  throw new Error(result.error ?? `Échec HTTP ${response.status}`);
}
console.log(result);
```

La clé est lue depuis l'environnement serveur; ne la remplacez pas par une valeur fictive dans le code client.
