# Pays, réseaux et tarifs

Le serveur expose trois routes de référence sans middleware d'authentification :

```bash
curl http://localhost:3000/api/reference/countries
curl http://localhost:3000/api/reference/networks
curl http://localhost:3000/api/reference/rates
```

Ces handlers appellent `getCountries()`, `getNetworks()` et `getMyRates()` dans le service SasPay puis renvoient la réponse fournisseur. Une erreur de ce service est renvoyée comme HTTP 500 par ces handlers.

Les pays, codes réseau, moyens de paiement et tarifs ne sont pas figés dans les routes PichFlow. Consultez les réponses courantes au lieu de vous fier à une liste statique dans la documentation. Les exemples d'autres pages utilisent `BJ`, `CI`, `SN`, `TG` et des codes comme `mtn_bj` uniquement comme valeurs de démonstration.

## Adresse de production

Dans ce dépôt, les chemins Express confirmés sont `/api/reference/...`. L'hôte public et un éventuel rewrite propre à l'hébergement ne sont pas configurés ici. Les exemples sont donc locaux; n'envoyez pas d'appel réel à une URL supposée.
