# Softpay & Confirmation OTP

L'endpoint **Softpay** de SasPay permet aux marchands d'initier un paiement direct Mobile Money sans rediriger le client vers une page externe lorsque l'opérateur prend en charge le push USSD.

---

## 1. Initialiser un paiement Softpay

L'en-tête `Idempotency-Key` est **obligatoire** pour cet appel afin de protéger votre utilisateur contre tout débit multiple intempestif en cas de micro-coupure réseau.

```bash
curl -X POST https://api.pichflow.com/v1/payments/softpay \
  -H "Authorization: Bearer sk_test_votre_cle" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: e3c45678-1234-4a5b-bcde-9876543210ab" \
  -d '{
    "amount": "10000.00",
    "currency": "XOF",
    "country": "BJ",
    "network": "mtn_bj",
    "customer": {
      "first_name": "Koffi",
      "last_name": "Sessou",
      "email": "koffi.sessou@example.com",
      "phone": "+22997123456"
    },
    "description": "Achat de crédits",
    "fee_charge_mode": "ADD_ON"
  }'
```

### Réponse :

```json
{
  "success": true,
  "data": {
    "id": "pay_soft_abc12345",
    "reference": "TX-PF-883491",
    "status": "pending",
    "amount": "10000.00",
    "network": "mtn_bj",
    "checkout_url": ""
  }
}
```

## 2. Confirmation par Code OTP (`confirm-otp`)

Certains réseaux télécoms (notamment Orange Money dans certains pays ou certaines banques partenaires) requièrent la saisie préalable d'un code OTP généré par le client sur son terminal avant la validation finale.

Si le statut retourné indique qu'un OTP est requis, utilisez l'endpoint officiel :

```bash
curl -X POST https://api.pichflow.com/v1/payments/pay_soft_abc12345/confirm-otp \
  -H "Authorization: Bearer sk_test_votre_cle" \
  -H "Content-Type: application/json" \
  -d '{
    "otp": "489201"
  }'
```

---

## 3. Relance d'un paiement (`retry`)

Si une transaction a échoué (ex: timeout de validation USSD par le client ou réseau momentanément indisponible) et que l'endpoint SasPay l'autorise, vous pouvez réinitier la tentative avec une nouvelle clé d'idempotence :

```bash
curl -X POST https://api.pichflow.com/v1/payments/pay_soft_abc12345/retry \
  -H "Authorization: Bearer sk_test_votre_cle" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: f9d8e7c6-b5a4-4321-9876-0123456789ab"
```
