# Gestion des Clients & Transactions

PichFlow centralise l'ensemble de vos flux financiers et vos carnets clients avec un niveau de détail élevé.

---

## 1. Lister et Filtrer les Transactions

Interrogez l'historique complet de vos encaissements :

```bash
curl -X GET "https://api.pichflow.com/v1/transactions?limit=20&status=success" \
  -H "Authorization: Bearer sk_test_votre_cle"
```

### Paramètres de recherche supportés

- `status` : Filtrer par `success`, `pending`, `failed`, `cancelled`.
- `limit` : Nombre de résultats par page (par défaut: 20, max: 100).
- `offset` : Décalage pour la pagination.
- `search` : Recherche textuelle par référence, email ou nom de client.
- `applicationId` : Filtrer sur une application spécifique de votre compte.

---

## 2. Export Comptable CSV

Téléchargez l'ensemble de votre relevé de transactions pour l'intégrer dans vos outils comptables (Excel, QuickBooks, SAP) :

```bash
curl -X GET "https://api.pichflow.com/v1/transactions/export?format=csv" \
  -H "Authorization: Bearer sk_test_votre_cle" \
  --output relevé_transactions_pichflow.csv
```

Le fichier CSV exporté contient :
- Référence de la transaction
- Date et heure UTC
- Nom, email et téléphone du client
- Opérateur et pays (ex: `MTN Bénin (BJ)`)
- Montant brut, frais de passerelle et montant net encaissé
- Statut final

---

## 3. Génération de Reçus et Factures PDF

Chaque transaction réussie dispose d'une route permettant d'éditer une facture normalisée au format PDF :

```bash
curl -X GET "https://api.pichflow.com/v1/transactions/tx_1728945600000/invoice" \
  -H "Authorization: Bearer sk_test_votre_cle" \
  --output facture_tx_1728945600000.pdf
```

---

## 4. Auto-Population des Clients

Dès qu'un client effectue un paiement valide :
1. PichFlow vérifie si l'adresse email existe déjà pour votre compte et cette application.
2. Si le client existe : son `total_spent` et son `payment_count` sont incrémentés, et sa date `last_transaction_at` est actualisée.
3. Si le client est nouveau : une fiche complète est immédiatement créée dans votre carnet d'adresses.
